# Análise Exploratória de Dados das Olimpíadas de 2024

Este repositório contém um Google Colab Notebook que realiza uma análise exploratória de dados (EDA) sobre as Olimpíadas de 2024. Este trabalho foi desenvolvido como parte da pós-graduação em Data Science e tem como objetivo extrair insights a partir dos dados relacionados aos jogos olímpicos.

## Objetivos do Projeto

- Realizar uma análise exploratória dos dados das Olimpíadas de 2024.
- Identificar padrões, tendências e relações entre variáveis relevantes.
- Criar visualizações claras e informativas para apresentar os resultados.
- Aplicar técnicas de Data Science adquiridas durante a pós-graduação.

## Ferramentas e Bibliotecas

As principais ferramentas e bibliotecas utilizadas neste projeto incluem:

- Python: Linguagem de programação para análise de dados.
- Pandas: Manipulação e análise de dados.
- Matplotlib e Seaborn: Visualizações gráficas.
- YdataProfilling: Facilita a criação de relatórios automatizados de análise exploratória de dados (EDA)
- Google Colab: Ambiente de execução do notebook.

## Dados Utilizados

Os dados das Olimpíadas de 2024 contêm informações como:
Atletas (nome, idade, gênero, nacionalidade, etc.).
Esportes e modalidades.
Resultados (medalhas, colocações, etc.).
Os dados foram repassados pelo professor do modulo.
